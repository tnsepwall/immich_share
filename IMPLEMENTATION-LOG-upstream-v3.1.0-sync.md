# Implementation Log — Upstream v3.1.0 Sync

**Merged:** upstream `v3.1.0` (130 commits, 689 files since `v3.0.3`) into the shared-libraries
fork on 2026-07-29. Merge base was exactly `v3.0.3` (`cd308ad93`), the fork's previous baseline.
Merge commit `6ad741bb2` + follow-up `e716037cf`.

## What upstream v3.1.0 brings (short version)

- **Search V3 groundwork** — a new composable filter engine in `utils/database.ts`
  (`branchPredicates` + a new `searchAssetBuilder`), with the old builder renamed to
  `searchAssetBuilderLegacy`. The V3 repository methods (`searchMetadataV3`,
  `searchStatisticsV3`) are **dead code in 3.1.0**: no controller, service, or web caller.
- **OIDC role claim sync** — admin status now syncs from the `immich_role` claim on *every*
  login, not just user creation (see upgrade guide for why this is safe for us).
- **Per-user people threshold** — the system ML `minFaces` value now seeds each user's
  `people.minimumFaces` preference via a data migration; the People page threshold is per-user
  from here on. (The preference field itself already existed at v3.0.3 — only the seeding and
  read-path switch are new.)
- Web: screen wakelock during uploads, archive undo toast, maintenance quick access in the
  command palette. Workflows: filter by server file path and by EXIF metadata. CLI: upload
  `--visibility` flag. Mobile: map date-range filter; iOS 14 support dropped.
- Session table gains an `oauthBearerToken` column (OAuth bearer-token sessions).
